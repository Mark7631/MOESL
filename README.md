# MOESL - My Own Emulator for Shell Language
## Общее описание
Это учебный проект по разработке эмулятора для языка оболочки ОС. Работа эмулятора должна быть как можно более похожей на работу в командной строке UNIX-подобной ОС. Эмулятор обладает собственной графической оболочкой. Графическая оболочка эмулятора включает в себя окно вывода, строка ввода и кнопку для исполнения введённой команды(вместо нажатия кнопки имеется возможность исполнить команду нажатием Enter на клавиатуре).

## Описние всех функций и настроек
Настройки - аргументы запуска программы:
- --vfs-path Обязательный параметр путь к VFS
- --cmd-promt Для изменения строки приглошения на пользовательскую
- --log-path Путь к отладочному файлу(csv), по умолчанию ./logs.csv
- --strt-scr-path Путь к стартовому скрипту
Эмулятор поддерживает команды:
- команды заглушки ls и cd, выводящие свое имя и аргументы
- команда exit для завершения работы программы
В случае ввода неизвестной команды выводится ошибка.

## Описание команд для сборки проекта и запуска тестов.
Для запуска необходимо иметь установленный python
### Первый вариант
Запуск с помощью run.bat --vfs-path "\<some path\>"
### Второй вариант
Самостоятельный запуск программы на Windows через консоль, открытую в корне папки проекта:
1. python -m venv .venv (создание виртуального окружения)
2. .venv\Scripts\activate (активация виртуального окружения)
3. python -m pip install --upgrade pip (обновление пакетного менеджера)
4. pip install -r requirements.txt (установка необходимых библиотек)
5. python ./src/main.py --vfs-path "\<some path\>" (запуск программы)
